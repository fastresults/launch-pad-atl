# Regenerate Mood Board — 9-tile art-directed set

## Current state (verified)

- Mood board tiles are generated by the `venture-brand-assets` edge function, `kind: "moodboard"`, and stored as `{ url, path }` entries in `venture_brand_kits.moodboard`.
- There are only 4 angle briefs (`MOODBOARD_ANGLES`), the default count is 4, and results are **prepended** to the existing tiles and capped at 8 — so regenerating leaves stale tiles behind.
- The only entry point is inside the wizard's "Moodboard & Logo" step. The final "Voice & Review" footer (where the selected Regenerate Website PRD button lives) has no mood board action, and neither does Brand Studio.
- Images upload to the `user-media` bucket with a `media_assets` row; there is a shared "regenerate means replace" helper (`_shared/replace-asset.ts`) used elsewhere.

## What we'll build

A **Regenerate Mood Board** action that produces a complete, coherent 9-tile board and fully replaces the previous board.

### 1. Nine distinct tile briefs

Expand the angle list from 4 to 9 so every tile has its own job and the board reads as one art-directed spread, not four repeats:

1. Texture / material macro
2. Customer's world — cinematic environment
3. Object still life
4. Colour & motion abstraction
5. Portrait / human moment in the brand's world
6. Architecture or space that carries the brand's structure
7. Typography-in-the-wild surface (signage, print, packaging — no readable brand text)
8. Detail crop of craft in progress (hands, tools, process)
9. Palette-forward hero frame that could sit behind a headline

Each brief inherits the venture's palette tokens, personality/mood adjectives and category context (the existing brand-kit context path), so the tiles are venture-specific rather than generic stock.

### 2. Regenerate means replace

- Generate all 9 first; only after tiles land successfully, delete the previous board's storage objects and `media_assets` rows, then write the fresh 9 as the whole `moodboard` array (no prepend/merge, cap raised to 9).
- If fewer than 9 succeed, keep what landed, still replace the old board only if at least 6 succeeded, and report the partial count; otherwise keep the old board and surface the error.

### 3. Run 9 without hitting the request ceiling

Nine image calls exceed the comfortable window of a single request, so the client drives the run in three batches of three (existing function accepts `count`), with a new `replace: true` flag on the final batch that triggers the cleanup step. Progress shows "Building tile 4 of 9…". Failures inside a batch are retried once before being reported.

### 4. Where the button lives

- **Wizard — Moodboard & Logo step:** the existing button becomes "Regenerate mood board (9 tiles)" with per-tile progress and a 3x3 grid.
- **Wizard — Voice & Review footer:** add a "Regenerate Mood Board" action beside Regenerate Website PRD, matching its treatment (full text label, spinner while running, enabled for both new-brand and existing-brand tracks).
- **Brand Studio panel:** same action next to the Website PRD rebuild row, so a locked brand can refresh its board without reopening the wizard.

All three call one shared hook so state, progress and errors are consistent.

### 5. States and feedback

- Idle: "Generate mood board" when empty, "Regenerate mood board" when a board exists.
- Running: spinner + "Building tile N of 9…", the button disabled only for the duration.
- Success: toast with the tile count and the grid refreshed in place.
- Failure or AI capacity limit: existing capacity dialog / error toast, old board untouched, retry available.

## Verification

- Regenerate on a venture with an existing 4-tile board: ends with exactly 9 tiles, old storage objects gone, no orphan `media_assets` rows.
- Tiles are visibly distinct from each other and use the venture's palette.
- Button appears and is fully readable in the Voice & Review footer at desktop and mobile widths.
- Forcing a mid-run failure leaves the previous board intact and shows a retryable error.
