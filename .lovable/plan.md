## Brand Studio → Guided Brand Wizard

Transform the static "Brand Studio" panel into a **5-step wizard** that walks founders through building a complete brand identity, then publishes a full Brand Style Guide deliverable that lands in **My Files** alongside their other documents.

---

### Current state (what's there today)

- `src/components/hub/BrandStudio.tsx` is a read-only panel that shows tokens already generated by AI (palette, fonts, mood) and offers four buttons: generate logo, generate social profile, copy logo prompt, export guidelines.
- The user has **zero input** into colors/fonts — they are inferred by `visual_identity_brief` AI generation.
- Three brand docs already exist in the framework: `brand_strategy_framework`, `visual_identity_brief`, `brand_voice_tone_guide`, plus a compiled `brand_guidelines_pdf`.
- There is no save-to-My-Files path from the Studio itself; only DocumentViewer has that capability.

### Problem

Founders can't actually *pick* their brand. The AI's first guess is final. There's no moodboard, no choice between palettes/typography pairs, and the resulting guidelines are buried in a markdown doc instead of a polished, ownable artifact.

---

### Proposed wizard (5 steps)

**Step 1 — Brand DNA (Discover)**
Pulls from existing venture context (concept, value prop, audience, track). Founder confirms or edits 4 inputs:
- Personality sliders (e.g. Modern↔Classic, Playful↔Serious, Bold↔Subtle, Premium↔Accessible)
- 3 mood adjectives (chips, AI-suggested + custom)
- 2-3 brands they admire (free text, used as reference)
- Audience reminder (read-only from snapshot)

**Step 2 — Color Palette (Choose)**
AI generates **4 distinct palette directions** (e.g. "Confident Minimal", "Warm Editorial", "Tech Forward", "Earthy Premium"), each a 6-swatch set (bg/fg/muted/accent/primary/secondary) with WCAG AA pairings pre-checked. Founder picks one, then can fine-tune any swatch with a color picker. "Regenerate options" button if none feel right.

**Step 3 — Typography (Choose)**
AI proposes **4 Google Font pairings** rendered as live previews (heading + body sample using the founder's own tagline). Founder picks one or swaps either font from a curated shortlist (12 heading + 12 body fonts). Shows weight/size scale preview.

**Step 4 — Moodboard & Logo (Visualize)**
- AI-generated 6-image moodboard (uses brand_tokens + mood adjectives via existing `venture-brand-assets` image gateway)
- 4 logo concepts generated with the locked palette/type
- Founder marks favorites (heart/star) — selections feed into the final guide
- Optional: upload existing logo if they already have one

**Step 5 — Voice & Review (Lock)**
- AI-drafted voice attributes (4 sliders) + 3 before/after copy examples, founder can tweak
- Final review screen: palette, type, mood, logo, voice in one polished layout
- Two CTAs:
  - **"Generate Brand Style Guide"** → produces a long-form, image-rich markdown document (covers, palette swatches with hex/RGB/usage, type specimens, logo lockups, moodboard, voice, do/don'ts, file-naming, governance)
  - **"Save to My Files"** → exports as DOCX + PDF into `attendee_documents` with source = "brand_studio"

---

### Persistence & integration

- New table `venture_brand_kits` keyed by `snapshot_id`: stores wizard state (dna, palette_choice, typography_choice, moodboard_asset_ids, logo_asset_ids, voice, status: draft/locked).
- On lock, write/replace the three existing brand docs (`brand_strategy_framework`, `visual_identity_brief`, `brand_voice_tone_guide`, `brand_guidelines_pdf`) so downstream deliverables (website PRD, social, pitch) reuse the founder's actual choices via `brand_tokens` on the snapshot.
- Save-to-My-Files reuses the existing `markdown-to-docx` + DocumentViewer export pipeline; PDF via the same browser print path already used elsewhere.
- Wizard is resumable — landing on Brand Studio shows progress and lets founder jump to any completed step.

### Technical notes

- All AI calls use Lovable AI Gateway (`google/gemini-3-flash-preview` for text, `google/gemini-3.1-flash-image` for moodboard/logo via existing `venture-brand-assets`).
- Contrast checker runs client-side; show AA/AAA badges next to each swatch pair.
- Fonts loaded on-demand via `@fontsource` dynamic imports for previews (no global CSS bloat).
- Save-to-My-Files writes one combined DOCX + one PDF (re-using DocumentViewer's existing export helpers), plus a copy of each selected logo asset.
- Wizard is gated only by the existing "Concept locked" rule — no new gates.
