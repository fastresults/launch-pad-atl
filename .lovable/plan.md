## What's happening

The "checkpoint" screens shown between blocks are recap cards meant to play back the user's answers in a short AI-written narrative before they continue. They render empty because all three summarizer functions are stubs that return `{ summary: "" }`:

- `summarizeBriefBlock` in `src/lib/brief.functions.ts`
- `summarizeFounderProfile` / `summarizeMarketProfile` in `src/lib/discovery.functions.ts`

`BlockCheckpoint.tsx` shows a skeleton, then "Generated by your AI assistant" and... nothing, because `data.summary` is `""` and `bullets` is missing. There is also no explanation of *what* a checkpoint is or *why* the user is seeing it, so even a working summary would feel abrupt.

## Fix — two parts

### 1. Make checkpoints self-explanatory and never empty (UI)

In `src/components/brief/BlockCheckpoint.tsx`:

- Replace the bare "Generated by your AI assistant" line with a short helper: **"Quick recap — make sure we heard you right before moving on."**
- Always render the user's own answers as a clean Q&A list inside the card (`fieldLabel(key)` → answer text), pulled from props. This guarantees content even before/if AI returns.
- Render the AI narrative + bullets *above* the Q&A list when present; otherwise show only the Q&A list with a quiet "AI recap unavailable — your answers below" note instead of a blank card.
- Tighten button copy: "Looks right — continue" / "Edit my answers".
- For founder/market blocks (no `fieldKeys`), pass a small set of label/value pairs from the founder/market profile rows.

Update `src/routes/_authenticated/dashboard/brief.tsx` to pass `answers: Array<{label, value}>` into `BlockCheckpoint` for each mode (QA block uses `block.fieldKeys` + `values`; founder/market pull from the discovery profile data already loaded for those screens).

### 2. Make the AI recap actually work (backend)

New Supabase Edge Function `brief-summarize-block`:
- Input: `{ kind: "qa" | "founder" | "market", title: string, answers: Array<{label, value}> }`.
- Calls Lovable AI Gateway with `google/gemini-3-flash-preview`, structured output via `Output.object({ summary: string, bullets: string[] })`.
- System prompt: warm second-person voice, 2–3 sentence summary that reflects the founder's words back to them, plus 3 short bullets ("What's clear", "What to watch", "Where you're headed"). No new facts; only reflect what was provided.
- Returns `{ summary, bullets }` or 4xx with a friendly message; client falls back to the Q&A list.

Wire client functions to call it:
- `summarizeBriefBlock({ block, content })` in `src/lib/brief.functions.ts` → invokes the edge function with the QA block's answers (built from `BRIEF_FIELDS` + brief row).
- `summarizeFounderProfile()` / `summarizeMarketProfile()` in `src/lib/discovery.functions.ts` → invoke with the founder/market profile fields.

Caller in `brief.tsx` passes the actual answers payload (not the current stub args) so the edge function has something to summarize.
