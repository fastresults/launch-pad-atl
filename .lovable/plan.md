## Plan: remove misleading “Saturday” timing copy

### Goal
Make the offer accurate everywhere: this is not specifically a Saturday event. The promise should be **built in a morning** / **one focused morning**, not “in one Saturday.”

### Copy rule to apply
- Replace **“one Saturday”**, **“Saturday morning”**, and similar scheduling-specific claims with flexible timing language:
  - “one morning”
  - “one focused morning”
  - “a morning session”
  - “built in a morning”
- Keep “Monday morning” only where it means the next practical workday after the workshop, unless it reads like the workshop must happen on a weekend.
- Avoid inventing a new branded phrase. This is a clarity sweep, not another naming exercise.

### Scope
I found “Saturday” references in:
- Homepage/source copy areas
- Public business-case assets
- Funnel/report markdown assets
- ICP/internal planning docs

I will update all user-facing and report-facing references that imply the workshop must happen on Saturday. Internal planning docs can also be cleaned so future copy does not reintroduce the same mistake.

### Replacement approach
Examples:
- “Your business — built with you, in one Saturday.” → “Your business — built with you, in one morning.”
- “one Saturday morning and $297” → “one focused morning and $297”
- “Show up Saturday morning” → “Show up for your morning session”
- “The Saturday that changes the math” → “The morning that changes the math”
- “You have Saturdays” → “You have a morning”

### Verification
After implementation, I’ll run a search for:
- `Saturday`
- `Saturdays`
- `one Saturday`
- `Saturday morning`

Then I’ll leave only any references that are clearly historical/report context and not marketing claims, or remove them if they could mislead prospects.
