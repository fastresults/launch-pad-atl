# StartupLabs Business Case Files

The registration-focused business case report is intentionally saved in multiple visible public formats:

- Markdown: `/business-case.md`
- Plain text: `/business-case.txt`
- Browser-formatted HTML: `/business-case.html`

If the file tree does not immediately show these files, refresh the editor file list. They are located in the project `public` folder and can be opened directly from the browser paths above.
